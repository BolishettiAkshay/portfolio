A modern, responsive, and performance-optimized personal portfolio web application built with **Vanilla HTML5, CSS3, and JavaScript**. Designed with a glassmorphism aesthetic, theme switcher (Dark/Light mode with system preference auto-detection), active scroll highlighting, and smooth entrance animations.

🌐 **Live Demo:** [https://bolishettiakshay.github.io/portfolio/](https://bolishettiakshay.github.io/portfolio/)

---

## 🌟 Key Portfolio Features

- **🎨 Modern Glassmorphism UI**: High-end visual aesthetic utilizing backdrop blurs, CSS custom property tokens, custom card borders, and smooth glowing hover transitions.
- **🌓 Dynamic Theme Switcher**:
  - Supports Dark and Light themes with seamless toggling.
  - Automatically respects user OS system color preference (`prefers-color-scheme`).
  - Persists theme state across browser sessions via `localStorage`.
- **📱 Fully Responsive Design**: Mobile-first architecture with custom hamburger menu, backdrop masks, and responsive grid layouts (desktop, tablet, mobile).
- **⚡ Scroll-Based Interactions**:
  - Sticky glass header with scroll shadow effect.
  - Automatic nav link highlighting for the visible section.
  - Smooth scroll behavior and `IntersectionObserver`-powered scroll reveal animations.
- **📄 Embedded Resume Access**: Direct options to view or download the SDE resume (`Akshay_Bolishetti_SDE_1.pdf`) in the header and hero sections.
- **📫 Contact Form Integration**: Interactive contact card supporting mailto links for immediate outreach.

## 🚀 Local Development Setup

To run and preview the portfolio locally on your machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/BolishettiAkshay/portfolio.git
   cd portfolio
   ```

2. **Open in Browser**:
   - Simply open `index.html` in any web browser.
   - Alternatively, serve it using any HTTP server (e.g. VS Code Live Server or `npx serve`):
     ```bash
     npx serve .
     ```
